Toyota Hiace (Patrullas Colombianas)
------------------------------------------------------------------------------------------------
Mod muy interesante, coche – Toyota Hiace (Patrullas Fajas) para GTA San Andreas. La textura es la calidad en un nivel alto. 

Características: 
Todas las piezas de automóvil puede ser dañado; 
- Soporta todas las funciones principales del juego; 
- No hay errores; 
- Un coche que se funde con el entorno de juego. 

Enlaces para descargar gratis de la moda Toyota Hiace (Patrullas Fajas) para GTA San Andreas, Usted puede encontrar a continuación en la página. Para instalar el mod en el juego tanto como Usted puede usar la instalación desatendida, y sin ella.

INSTRUCCIONES DE INSTALACIÓN
------------------------------------------------------------------------------------------------
1. Importación de archivos en el archivo IMG
No puede descargar IMG Manager 2.0 aquí: http://www.gtaall.net/gta-san-andreas/programs/37425-img-manager-20.html
Crazy IMG Editor aquí: http://www.gtaall.net/gta-san-andreas/programs/3884-gta-sa-crazy-img-editor.html

Utilice IMG Manager 2.0 o loco IMG Editor para importar archivos desde la carpeta "01 - Import to gta3.img" para archivar [JUEGO CARPETA]\models\gta3.img:
copcarla.dff
copcarla.txd
------------------------------------------------------------------------------------------------
