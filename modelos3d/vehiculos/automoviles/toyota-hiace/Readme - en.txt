Toyota Hiace (Patrullas Colombianas)
------------------------------------------------------------------------------------------------
Mod interesting car – Toyota Hiace (Patrullas Colombianas) for GTA San Andreas. Texture quality is on high level. 

Features: 
All car parts can be damaged; 
- Supports all major functions of the game; 
- No bugs; 
- A car that blends in with the game environment.

INSTALLATION INSTRUCTIONS
------------------------------------------------------------------------------------------------
1. Import files in the IMG archive
You can download IMG Manager 2.0 here: http://www.gtaall.com/gta-san-andreas/programs/37425-img-manager-20.html
Crazy IMG Editor here : http://www.gtaall.com/gta-san-andreas/programs/3884-gta-sa-crazy-img-editor.html

Use IMG Manager 2.0 or Crazy IMG Editor to import files from the folder "01 - Import to gta3.img" to archive [GAME FOLDER]\models\gta3.img:
copcarla.dff
copcarla.txd
------------------------------------------------------------------------------------------------
2. Changes in text files

In file [Game folder]\data\vehicles.ide
Find the line that starts with
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	
Replace found line with
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	null,	ignore,		10,	0,	0,		-1, 0.7, 0.7,	-1

In file [Game folder]\data\handling.cfg
Find the line that starts with
POLICE_LA 
Replace found line with
POLICE_LA    1600.0    4500.0   2.0    0.0 0.3 -0.1  75  0.75 0.85 0.50 	5 200.0 25.0 10.0 R P 	10.0  0.53 0 35.0  	1.0  0.12  0.0   0.28 -0.12 0.55 0.0		0.2  0.24 25000 	40000000	10200008	0  1	0

In file [Game folder]\data\carcols.dat
Find the line that starts with
copcarla, 
Replace found line with
copcarla, 0,1

In file [Game folder]\data\carmods.dat
Find the line that starts with
copcarla, 
Replace found line with
copcarla, nto_b_l, nto_b_s, nto_b_tw
