Toyota Hiace (Patrullas Colombianas)
------------------------------------------------------------------------------------------------
Mod intéressant de voiture Toyota Hiace (Patrullas Colombianas) pour GTA San Andreas. La qualité de la Texture est de haut niveau. 

Caractéristiques: 
Toutes les pièces d'une voiture peut être endommagé; 
- Prend en charge toutes les fonctions principales du jeu; 
- Pas de bugs; 
- Une voiture qui s'intègre parfaitement dans l'environnement de jeu. 

Liens de téléchargement gratuit de la mode Toyota Hiace (Patrullas Colombianas) pour GTA San Andreas Vous pouvez trouver ci-dessous sur la page. Pour installer le mod dans le jeu, Vous pouvez à l'aide de l'installation sans assistance, et sans elle.

INSTRUCTIONS D'INSTALLATION
------------------------------------------------------------------------------------------------
1. Importer des fichiers dans l'archive IMG
Vous pouvez télécharger IMG Manager 2.0 ici: http://www.gtaall.eu/fr/gta-san-andreas/programs/37425-img-manager-20.html
Crazy IMG Editor ici: http://www.gtaall.eu/fr/gta-san-andreas/programs/3884-gta-sa-crazy-img-editor.html

Utilisez IMG Manager 2.0 ou fou IMG Editor d'importer des fichiers à partir du dossier "01 - Import to gta3.img" pour archiver [JEU DOSSIER]\models\gta3.img:
copcarla.dff
copcarla.txd
------------------------------------------------------------------------------------------------
2. Changements dans des fichiers texte

Dans le fichier [Dossier du jeu]\data\vehicles.ide
Trouvez la ligne qui commence par
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	
Remplacer trouvé ligne avec
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	null,	ignore,		10,	0,	0,		-1, 0.7, 0.7,	-1

Dans le fichier [Dossier du jeu]\data\handling.cfg
Trouvez la ligne qui commence par
POLICE_LA 
Remplacer trouvé ligne avec
POLICE_LA    1600.0    4500.0   2.0    0.0 0.3 -0.1  75  0.75 0.85 0.50 	5 200.0 25.0 10.0 R P 	10.0  0.53 0 35.0  	1.0  0.12  0.0   0.28 -0.12 0.55 0.0		0.2  0.24 25000 	40000000	10200008	0  1	0

Dans le fichier [Dossier du jeu]\data\carcols.dat
Trouvez la ligne qui commence par
copcarla, 
Remplacer trouvé ligne avec
copcarla, 0,1

Dans le fichier [Dossier du jeu]\data\carmods.dat
Trouvez la ligne qui commence par
copcarla, 
Remplacer trouvé ligne avec
copcarla, nto_b_l, nto_b_s, nto_b_tw
