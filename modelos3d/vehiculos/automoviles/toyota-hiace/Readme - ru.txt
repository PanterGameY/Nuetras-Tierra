ИНСТРУКЦИИ ПО УСТАНОВКЕ
------------------------------------------------------------------------------------------------
1. Импорт файлов в IMG архив
IMG Manager 2.0 Вы можете скачать тут: http://www.gtavicecity.ru/gta-san-andreas/programs/37425-img-manager-20.html
Crazy IMG Editor тут: http://www.gtavicecity.ru/gta-san-andreas/programs/3884-gta-sa-crazy-img-editor.html

С помощью программы IMG Manager 2.0 или Crazy IMG Editor импортируйте следующие файлы из папки "01 - Import to gta3.img" в архив [Папка с игрой]\models\gta3.img:
copcarla.dff
copcarla.txd
------------------------------------------------------------------------------------------------
2. Изменения в текстовых файлах

В файле [Папка с игрой]\data\vehicles.ide
Найдите строку, которая начинается с
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	
Замените всю найденную строку на
596, 	copcarla, 	copcarla, 	car, 		POLICE_LA, 	POLICAR,	null,	ignore,		10,	0,	0,		-1, 0.7, 0.7,	-1

В файле [Папка с игрой]\data\handling.cfg
Найдите строку, которая начинается с
POLICE_LA 
Замените всю найденную строку на
POLICE_LA    1600.0    4500.0   2.0    0.0 0.3 -0.1  75  0.75 0.85 0.50 	5 200.0 25.0 10.0 R P 	10.0  0.53 0 35.0  	1.0  0.12  0.0   0.28 -0.12 0.55 0.0		0.2  0.24 25000 	40000000	10200008	0  1	0

В файле [Папка с игрой]\data\carcols.dat
Найдите строку, которая начинается с
copcarla, 
Замените всю найденную строку на
copcarla, 0,1

В файле [Папка с игрой]\data\carmods.dat
Найдите строку, которая начинается с
copcarla, 
Замените всю найденную строку на
copcarla, nto_b_l, nto_b_s, nto_b_tw
